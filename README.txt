Miele Delay 1.0.0

Финальная сборка приложения для расчёта отсрочки запуска Miele WEI875 WPS.

Приложение запоминает длительность конкретных комбинаций:
программа + температура + отжим + дополнительные опции.

Если комбинация неизвестна, пользователь вводит время, показанное стиральной машиной.
Расчёт отсрочки выполняется с шагом 15 минут.

Настройки содержат вкладки «Основные» и «Справочники».
